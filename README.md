## 🚀 Getting Started

### Prerequisites

- Java JDK 17 or later (or your installed version)
- Visual Studio Code / IntelliJ IDEA / Eclipse
- Java Extension Pack (for VS Code)

### Clone the Repository

```bash
git clone https://github.com/<your-username>/java-snippets.git
```

Navigate to the project:

```bash
cd java-snippets
```

Compile a Java file:

```bash
javac FileName.java
```

Run the program:

```bash
java FileName
```

## 💡 Example

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

Output:

```
Hello, Java!
```
